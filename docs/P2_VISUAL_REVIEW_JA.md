# P2 ステージ候補の外観審査

各コースをB3.8で読み込む前に、同じ2視点（全体俯瞰・低い側面）で比較する。

## 必須確認
1. 走行路を非表示にしても構造物として成立するか
2. 一目で別の系統と分かるか（色・マテリアル違いだけでは不可）
3. 遠景シルエットが大胆か。実機の視点でボールが見えるか
4. 細部（リブ、接合部、外殻の割れ目、段状の断面）が単純反復ではないか
5. 外装とゲーム本体側の照明・遠景・演出が分担できるか
6. 曲面境界、視界遮蔽、装飾の物理当たり判定を最優先で確認

評価は採用を決める材料であって、機械的な点数だけで採否は決めない。

## このバッチの注意
- HC-001: 巨大円筒内の視認性と出口の経路確認
- TF-001: 大きな折板による通路遮蔽と外殻間の隙間
- AF-001: 崖面が走行路を隠す角度、開口のリズム
- FM-001: 大型立方体の内部・外部での視界の変化
